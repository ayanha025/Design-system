# Color

컬러 토큰은 두 단계로 나뉩니다.

- **Semantic** — 용도에 따라 이름 붙인 색상입니다 (`--color-primary-default`, `--color-label-primary` 등). **컴포넌트는 Semantic 토큰만 사용합니다.**
- **Primitive** — 실제 색상 팔레트입니다. Semantic 토큰의 원재료이며 컴포넌트에서 직접 쓰지 않습니다.

이렇게 나누면 브랜드 컬러를 바꿀 때 Semantic 토큰이 가리키는 값만 바꾸면 됩니다.
견본을 클릭하면 `var(--...)` 코드가 복사됩니다.
